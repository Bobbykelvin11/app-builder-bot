# App Builder

Describe an app idea and get a starter Flutter `lib/main.dart`. The project has three parts:

| Part | Where | What it does |
| --- | --- | --- |
| Generator API + web UI | `vercel/` (deployed on Vercel) | `POST /api/generate` turns a prompt into Flutter source. `/` is a small web UI with copy and download. |
| Mobile app (Android + iOS) | `mobile/` (Flutter) | Build, History (offline) and Settings tabs; calls the API. |
| Legacy local server + Telegram bot | `server/` | Original FastAPI/Telegram starter for running on your own machine. Optional. |

> **Important:** App Builder writes source code. It is not compiled or tested, and it is not an installable app by itself. An unsigned IPA must be signed (for example with Sideloadly or AltStore) before it installs on an iPhone.

## Generator API (Vercel)

`vercel/api/generate.js` is a dependency-free Node.js serverless function.

```http
POST /api/generate
Content-Type: application/json
X-App-Key: <your APP_KEY>

{"prompt": "A habit tracker with streaks"}
```

Response: `{"file": "lib/main.dart", "code": "...", "model": "...", "provider": "..."}`.
Errors return `{"error": "<code>", "detail": "<human-readable message>"}` with 400, 401, 405, 429, 502, 503 or 504.

Features: shared-secret `X-App-Key` check (constant-time), prompt validation (8–4000 characters), best-effort per-IP rate limit (`RATE_LIMIT_PER_MIN`, default 6), upstream timeout (`OPENAI_TIMEOUT_MS`, default 50 s, function `maxDuration` 60 s), markdown-fence stripping, and redacted upstream errors.

### Environment variables (set in the Vercel project, never in git)

| Variable | Required | Purpose |
| --- | --- | --- |
| `APP_KEY` | yes | Shared secret clients send as `X-App-Key`. |
| `OPENAI_API_KEY` | no | If set, requests go straight to OpenAI (`OPENAI_MODEL`, default `gpt-4o-mini`). |
| `AI_GATEWAY_MODEL` | no | Model used when there is no OpenAI key (default `openai/gpt-4.1-mini`). |
| `AI_GATEWAY_API_KEY` | no | Only needed outside Vercel. On Vercel the function uses the deployment's OIDC token for **Vercel AI Gateway**, which includes free monthly credits. |

### Deploy

Create a Vercel project with **Root Directory = `vercel`** and framework preset **Other**, add the variables above, and deploy. Or from a terminal: `cd vercel && vercel deploy --prod`.

## Mobile app

`mobile/` is a Flutter project (`http`, `shared_preferences`, `share_plus`). Android and iOS platform folders are generated by `mobile/tool/prepare_platforms.sh`, which sets:

- Bundle / application ID: `com.bobbymedia.appbuilder`
- Display name: **App Builder**
- Android `INTERNET` permission

Screens:

- **Build** – prompt box with validation, example ideas, loading state, offline banner, and auto-saved draft.
- **Result** – monospace, selectable code with Copy and Share.
- **History** – every result saved on the device; works offline; swipe to delete.
- **Settings** – override the server URL and App key, theme (system/light/dark), clear history.

Build-time settings use `--dart-define`:

```bash
cd mobile
bash tool/prepare_platforms.sh android
flutter build apk --release \
  --dart-define=API_BASE_URL=https://your-project.vercel.app \
  --dart-define=APP_KEY=your-app-key
```

## Build APK / unsigned IPA with GitHub Actions

1. Optional: add a repository **secret** `APP_KEY` so the app ships with the key built in. Without it, users paste the key once in Settings. Never pass the key as a workflow input; inputs are shown in plain text.
2. Optional: add a repository **variable** `API_BASE_URL`, or type it in the run form.
3. Open **Actions → Build mobile artifacts → Run workflow**.
4. Download `android-apk` (universal + arm64 APK) and `unsigned-ios-ipa` from the run's **Artifacts**.

The workflow runs `flutter analyze` and `flutter test` first, then builds Android on Linux and iOS on macOS with Flutter 3.50.1.

## Legacy local server

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
export OPENAI_API_KEY="your-key"
uvicorn server.main:app --reload
```

For Telegram, also set `TELEGRAM_BOT_TOKEN`, then run `python -m server.telegram_bot`.
